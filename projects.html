MASTER'S THESIS

Developed a human detection and tracking algorithm using YOLOv8 on the ROBOTNIK SUMMIT XL platform. The core idea is intended to be implemented in hospitals to assist medical doctors during ward rounds, in cases where nurses are lacking. I focused on creating the code for tracking, perception, and motor control. I established the ROS communication that will enable synergy between the remote workstation and the robot. This work contributes to low-cost sensor fusion by utilizing only a monocular RGB Camera.

SAFETY-AWARE MOBILE ROBOT NAVIGATION

Designed a reinforcement learning (RL) algorithm that enables the Buggy Robot to make decisions based on actions and rewards. Its objective is to perform a fixed navigation task, and while at it, it avoids colliding with other objects on its navigation pathway and finds an alternative path, or it stops for the object to be taken out before it continues.
